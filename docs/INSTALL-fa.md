## 1. پیش‌نیازها

| مورد | حداقل | پیشنهاد |

| افزونه HostDL | اختیاری | 1.0.5 |

## 2. نصب افزونه

### روش 1: از پیشخوان وردپرس
1. فایل `taranehyar-scout.zip` را دانلود کنید
2. از پیشخوان: افزونه‌ها > افزودن > بارگذاری افزونه
3. فایل ZIP را انتخاب و نصب کنید
4. فعال‌سازی

### روش 2: FTP
1. فایل ZIP را باز کنید
2. پوشه `taranehyar-scout` را به `/wp-content/plugins/` آپلود کنید
3. از پیشخوان، افزونه را فعال کنید

## 3. پس از نصب

پس از فعال‌سازی:

1. جداول دیتابیس به صورت خودکار ایجاد می‌شوند:
   - `wp_taranehyar_scout_discoveries`
   - `wp_taranehyar_scout_jobs`
   - `wp_taranehyar_scout_logs`

2. تنظیمات پیش‌فرض ذخیره می‌شود

3. Cron jobها زمان‌بندی می‌شوند:
   - `tscout_process_queue` هر 5 دقیقه
   - `tscout_cleanup` روزانه

## 4. پیکربندی

### 4.1 تنظیمات ترانه‌یار (اگر نصب است)

اگر افزونه اصلی ترانه‌یار نصب است:

1. به پنل موزیک > تنظیمات بروید
2. آدرس هاست دانلود و توکن را وارد کنید
3. این تنظیمات برای اسکات هم استفاده می‌شود

### 4.2 تنظیمات اسکات

به اسکات > تنظیمات بروید:

#### تطبیق
- آستانه تطبیق دقیق: 95% (پیش‌فرض)
- آستانه تطبیق بالا: 80%
- آستانه تطبیق متوسط: 60%

#### جستجو
- حداکثر نتایج: 50
- timeout: 30 ثانیه
- پاک‌سازی: 30 روز

#### ارائه‌دهندگان
برای هر ارائه‌دهنده:

- **فعال**: آیا جستجو از این منبع انجام شود؟
- **مجوز پیش‌فرض**: 
  - تأیید شده: فایل‌ها قابل انتقال هستند
  - نیاز به بررسی: باید مجوز تأیید شود (پیش‌فرض امن)
  - فقط متادیتا: فقط اطلاعات متنی
  - فایل مجاز، تأیید نشده: فایل قابل دریافت اما بازنشر نامشخص
  - ممنوع: استفاده ممنوع
- **اجازه دانلود صوتی**: آیا فایل صوتی دانلود شود؟
- **اجازه دانلود کاور**: آیا کاور دانلود شود؟

**توصیه امنیتی**: برای MyBia2Music، مجوز را روی "نیاز به بررسی" بگذارید و دانلود صوتی را غیرفعال کنید تا از انتشار بدون مجوز جلوگیری شود.

## 5. استفاده

### 5.1 کشف آثار

1. به اسکات > کشف آثار بروید
2. نام انگلیسی هنرمند را وارد کنید، مثلاً `Mohsen Yeganeh`
3. منابع را انتخاب کنید (پیش‌فرض: MyBia2Music)
4. نوع آثار و تعداد نتایج را مشخص کنید
5. شروع جستجو را بزنید
6. پیشرفت را مشاهده کنید (ممکن است 1-2 دقیقه طول بکشد)
7. پس از اتمام، به نتایج کشف بروید

### 5.2 بررسی نتایج

در اسکات > نتایج کشف:

- فهرست آثار با فیلترهای مختلف
- وضعیت تطبیق:
  - منتشر نشده: آماده انتشار
  - منتشر شده: قبلاً در سایت وجود دارد
  - احتمال تکراری: شباهت بالا
  - نیاز به بررسی: شباهت متوسط، نیاز به بررسی دستی
- مجوز:
  - تأیید شده: قابل انتشار
  - نیاز به بررسی: باید تأیید شود
  - فقط متادیتا: فایل منتقل نمی‌شود
- عملیات:
  - پیش‌نمایش: مشاهده جزئیات و محتوای پست
  - انتشار: ایجاد پست (پیش‌نویس یا منتشر شده)

### 5.3 انتشار

1. روی پیش‌نمایش کلیک کنید
2. اطلاعات را بررسی کنید:
   - عنوان، هنرمند، منبع
   - وضعیت تطبیق و دلیل
   - وضعیت فایل‌ها
   - هشدارها
3. اگر مجوز نیاز به بررسی دارد، تیک تأیید را بزنید
4. انتشار را تأیید کنید
5. پست ایجاد می‌شود (پیش‌نویس به صورت پیش‌فرض)

### 5.4 انتقال فایل‌ها

اگر هاست دانلود پیکربندی شده و مجوز اجازه دهد:

- فایل‌ها به صورت خودکار به هاست دانلود منتقل می‌شوند
- وضعیت را در اسکات > وضعیت انتقال‌ها ببینید
- در صورت خطا، تلاش مجدد بزنید

اگر هاست دانلود نباشد یا مجوز اجازه ندهد:

- فقط متادیتا منتشر می‌شود
- یا در صورت فعال بودن "اجازه URL خارجی"، لینک خارجی استفاده می‌شود

## 6. WP-Cron

صف پردازش با WP-Cron کار می‌کند که وابسته به بازدید سایت است.

### برای سایت‌های کم‌بازدید:

Cron واقعی هاست را به `wp-cron.php` وصل کنید:

```bash
*/5 * * * * wget -q -O - https://yoursite.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

یا:

```bash
*/5 * * * * curl -s https://yoursite.com/wp-cron.php?doing_wp_cron > /dev/null
```

## 7. عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| جستجو نتیجه نمی‌دهد | نام انگلیسی را بررسی کنید، ارائه‌دهنده فعال باشد، لاگ را ببینید |
| تطبیق کار نمی‌کند | آرشیو سایت را بررسی کنید، آستانه‌ها را کم کنید |
| انتشار ناموفق | مجوز را بررسی کنید، ترانه‌یار فعال باشد، لاگ خطا |
| فایل منتقل نمی‌شود | هاست دانلود پیکربندی شده؟ توکن درست است؟ مجوز اجازه می‌دهد؟ |
| صف اجرا نمی‌شود | WP-Cron فعال است؟ Cron واقعی تنظیم کنید |

### مشاهده لاگ:

```sql
SELECT * FROM wp_taranehyar_scout_logs ORDER BY created_at DESC LIMIT 50;
```

یا از طریق کد:

```php
$logs = \TaranehyarScout\Logging\Logger::get_logs(50);
```

## 8. حذف افزونه

از پیشخوان: افزونه‌ها > ترانه‌یار اسکات > حذف

به صورت پیش‌فرض، داده‌ها حفظ می‌شوند. برای حذف کامل:

1. به تنظیمات اسکات بروید (اگر وجود دارد)
2. گزینه "حذف داده‌ها هنگام حذف" را فعال کنید (در نسخه‌های آینده)
3. یا دستی جداول را حذف کنید:

```sql
DROP TABLE wp_taranehyar_scout_discoveries;
DROP TABLE wp_taranehyar_scout_jobs;
DROP TABLE wp_taranehyar_scout_logs;
DELETE FROM wp_options WHERE option_name = 'tscout_options';
```
