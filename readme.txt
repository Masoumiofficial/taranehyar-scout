== Description ==

**ترانه‌یار اسکات | Taranehyar Scout** ابزاری هوشمند برای سایت‌های موسیقی است که به شما کمک می‌کند آثار هنرمندان را از منابع مجاز کشف، با آرشیو سایت خود تطبیق و به صورت کنترل‌شده منتشر کنید.

= شعار =
کشف کن، تطبیق بده، هوشمندانه منتشر کن.

= ویژگی‌های کلیدی =

* موتور جستجوی چندمنبعی با providerهای مستقل
* پشتیبانی از MyBia2Music و سایر منابع مجاز
* استانداردسازی متادیتا و تشخیص نوع اثر (تک‌آهنگ، آلبوم، ریمیکس، اجرای زنده، همکاری)
* تطبیق هوشمند چندمرحله‌ای با آرشیو سایت
* پنل مدیریت فارسی و راست‌چین
* خط لوله انتشار مرحله‌ای و قابل‌ردیابی
* یکپارچگی با افزونه اصلی Taranehyar و Taranehyar HostDL
* مدیریت مجوز و حقوق استفاده (متادیتا، کاور، فایل صوتی جداگانه)
* صف پس‌زمینه با WP-Cron و مدیریت پیشرفت
* امنیت کامل: ضد SSRF, XSS, CSRF, Path Traversal
* لاگ و گزارش کامل عملیات

= جریان کاری =

1. ورود به پنل مدیریت وردپرس
2. باز کردن بخش ترانه‌یار اسکات
3. وارد کردن نام انگلیسی خواننده (مثل Mohsen Yeganeh)
4. انتخاب منابع جستجو و اجرای کشف
5. مشاهده آثار پیدا شده با منبع، نوع و میزان اطمینان
6. بررسی وضعیت هر اثر در آرشیو سایت
7. انتخاب آثار برای پردازش
8. مشاهده پیش‌نمایش و وضعیت مجوز
9. تأیید و انتشار

= نیازمندی‌ها =

* وردپرس 5.8 یا بالاتر
* PHP 7.2 یا بالاتر (پیشنهاد 8.1+)
* افزونه اصلی Taranehyar (اختیاری اما پیشنهاد می‌شود)
* افزونه Taranehyar HostDL برای انتقال فایل‌ها (اختیاری)

= نصب =

1. افزونه را نصب و فعال کنید
2. به بخش اسکات > تنظیمات بروید
3. ارائه‌دهندگان و سیاست‌های مجوز را پیکربندی کنید
4. از بخش کشف آثار، جستجوی خود را آغاز کنید

== Frequently Asked Questions ==

= آیا این افزونه بدون ترانه‌یار کار می‌کند؟ =
بله، افزونه به صورت مستقل قابل نصب است. اما برای انتشار کامل آثار با ساختار ترانه‌یار، وجود افزونه اصلی پیشنهاد می‌شود. در صورت نبود ترانه‌یار، خطای Fatal ایجاد نمی‌شود.

= آیا فایل‌های صوتی بدون مجوز منتقل می‌شوند؟ =
خیر. به صورت پیش‌فرض، همه فایل‌ها وضعیت "نیاز به بررسی مجوز" دارند و تا تأیید مدیر منتقل نمی‌شوند. قابل‌دسترسی بودن فایل در وب به معنی مجاز بودن بازنشر نیست.

= چگونه provider جدید اضافه کنم؟ =
راهنمای کامل در فایل docs/PROVIDER_GUIDE.md موجود است. کافی است کلاس جدیدی بسازید که ProviderInterface را پیاده‌سازی کند و از طریق فیلتر tscout_providers ثبت کنید.

= آیا از دور زدن محدودیت‌ها استفاده می‌کند؟ =
خیر. افزونه از دور زدن CAPTCHA، احراز هویت، paywall یا کنترل‌های ضدربات خودداری می‌کند. فقط داده‌های مجاز و عمومی دریافت می‌شود.
